# Frontline RCON Suite v0.9.1

## Deutsch

Hotfix auf Basis von v0.9.0.

- **Aurora: Spielstatus wieder sichtbar.** Die Kopfzeile zeigt die Gesamtspielerzahl mit Serverkapazität, die aktuelle Karte samt Spielmodus und die verbleibende Spielzeit. Auf kleinen Bildschirmen stehen diese Informationen in einer eigenen kompakten Zeile. Die Anzeige nutzt die bestehenden Serverabfragen; veraltete Daten werden gekennzeichnet und der Countdown bei veralteten Spieldaten angehalten.
- **Zuverlässigere Anmeldung und Bedienung.** Fehlende oder nach einer Anmeldung veraltete CSRF-Tokens werden koordiniert erneuert, auch bei mehreren geöffneten Tabs und parallelen Anfragen. Klar erkennbare Token-Ablehnungen werden höchstens einmal wiederholt. Berechtigungsfehler, nicht vertrauenswürdige Ursprünge, Netzwerkfehler und unklare Aktionsergebnisse werden nicht automatisch wiederholt. Der CSRF-Schutz bleibt aktiv.
- **Prüfungen ergänzt.** Zusätzliche Browser- und Sicherheitstests decken die responsive Statusanzeige, Verbindungsabbrüche und Sitzungswechsel ab.

### Hinweise für Administratoren

- Vor einem späteren Rollout Datenbank und Konfiguration sichern und **Backend und Frontend gemeinsam auf v0.9.1** aktualisieren. Anschließend geöffnete RCON-Seiten neu laden.
- Keine neuen Datenbankmigrationen gegenüber v0.9.0. Vorhandene Berechtigungen, Themes und Servereinstellungen bleiben erhalten.
- Dieses Hotfix veröffentlicht keine neue „Was ist neu?“-Einblendung. Die Änderungen sind im Update-Kanal nachlesbar.
- Die Veröffentlichung allein führt keinen Rollout auf RCON- oder Gameservern durch.

## English

Hotfix based on v0.9.0.

- **Aurora: match status is visible again.** The toolbar shows the total player count and server capacity, current map and game mode, and remaining match time. Small screens use a separate compact row. The display reuses existing server queries; stale values are marked and the countdown pauses when game data is stale.
- **More reliable sign-in and actions.** Missing or outdated CSRF tokens are refreshed in a coordinated way, including across open tabs and concurrent requests. Explicit token rejections are retried at most once. Permission failures, untrusted origins, network failures and uncertain action outcomes are never retried automatically. CSRF protection remains enabled.
- **Additional verification.** Browser and security tests cover the responsive status display, connection failures and session changes.

### Administrator notes

- Before a subsequent rollout, back up the database and configuration and update **both backend and frontend to v0.9.1**. Reload open RCON pages afterwards.
- No new database migrations compared with v0.9.0. Existing permissions, themes and server configuration are preserved.
- This hotfix does not introduce a new automatic “What’s new?” popup. Its changes remain available in the update channel.
- Publishing the release does not deploy it to RCON or game-server installations.
