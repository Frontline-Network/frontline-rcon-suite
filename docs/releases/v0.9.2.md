# Frontline RCON Suite v0.9.2

## Deutsch

Kleines Hotfix auf Basis von v0.9.1.

- **Hinweise auf neue Funktionen bleiben sichtbar.** Wer die Neuerungen aus v0.9.0 noch nicht gesehen hat, bekommt den ursprünglichen „Was ist neu?“-Hinweis auch nach einem Hotfix weiterhin auf der Übersichtsseite angezeigt. Dazu gehören die neuen Aurora-Farbstile und die persönliche Gestaltung des RCON.
- **Keine erneute Einblendung nach Bestätigung.** Bereits gelesene Hinweise und „Später“-Entscheidungen bleiben pro Benutzerkonto erhalten, auch auf anderen Geräten. Über das Benutzermenü und den Update-Kanal lässt sich der Hinweis weiterhin manuell öffnen. Das Changelog zeigt getrennt davon die tatsächlich installierte Version.
- **Passwort-Wiederherstellung bei mehreren Instanzen abgesichert.** Aktivierung und öffentliche HTTPS-Adresse können je RCON-Instanz festgelegt werden. SMTP-Einstellungen bleiben bei entsprechend vorbereiteten Rollouts erhalten; Reset-Links führen zum richtigen RCON. Bestehende Einzelserver-Konfigurationen bleiben kompatibel.

### Hinweise für Administratoren

- Vor einem Rollout Datenbank und Konfiguration sichern und **Backend und Frontend gemeinsam auf v0.9.2** aktualisieren. Anschließend geöffnete RCON-Seiten neu laden.
- Keine neuen Datenbankmigrationen gegenüber v0.9.1. Vorhandene Lesestände werden nicht zurückgesetzt. Dieses Hotfix erhält die ursprüngliche v0.9.0-Einblendung, statt alle Benutzer erneut zu benachrichtigen.
- Passwort-Wiederherstellung bleibt standardmäßig deaktiviert. SMTP-Zugangsdaten gehören in die private `.env`, nicht ins Release. Benutzer benötigen eine eigene hinterlegte E-Mail-Adresse.
- Die Veröffentlichung allein führt keinen Rollout auf RCON- oder Gameservern durch. Automods, Abstimmungen und Spielregeln werden nicht verändert.

## English

Small hotfix based on v0.9.1.

- **Feature announcements survive hotfix updates.** Users who have not yet seen the v0.9.0 changes still receive the original “What's new?” announcement on the overview page after installing a hotfix. This includes the new Aurora colour styles and personal RCON appearance settings.
- **No repeated popup after acknowledgement.** Read and “Later” states remain attached to each user account, including across devices. The user menu and update channel still offer manual access to the announcement. The changelog separately shows the version actually installed.
- **Multi-instance password recovery is safer to deploy.** Activation and public HTTPS origins can be configured per RCON instance. Properly prepared rollouts preserve SMTP settings, and reset links return to the correct instance. Existing single-server configurations remain compatible.

### Administrator notes

- Before rollout, back up the database and configuration and update **both backend and frontend to v0.9.2**. Reload open RCON pages afterwards.
- No new database migrations compared with v0.9.1. Existing acknowledgement states are not reset. This hotfix preserves the original v0.9.0 announcement instead of notifying every user again.
- Password recovery remains disabled by default. SMTP credentials belong in the private `.env`, not in release content. Each user needs their own email address stored on their account.
- Publishing this release does not deploy it to RCON or game-server installations. Automods, votes and game rules are unchanged.
