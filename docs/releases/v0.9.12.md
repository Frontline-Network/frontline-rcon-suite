# Frontline RCON Suite v0.9.12

## Deutsch

v0.9.12 ist ein wichtiges Hotfix für die mit v0.9.11 eingeführte schlanke
gemeinsame RCON-Laufzeit. Die neue Runtime startete den Live-Ereignisloop ohne
die zentrale Handler-Registrierung. Periodische Dienste liefen weiter, aber
einige unmittelbar durch Chat, Spielerbeitritt, Kills oder Rundenwechsel
ausgelöste Funktionen reagierten nicht.

### Wiederhergestellte Ereignisfunktionen

- VIP-Belohnungen erhalten wieder Kill-, Chat-, Verbindungs-, Teamwechsel- und
  Rundenereignisse. Der Statusbefehl und die freiwillige Balance-Anmeldung
  werden wieder erkannt.
- Der Autobalancer verarbeitet wieder `!balance`, Kills, Teamkills,
  Teamwechsel sowie Start und Ende einer Runde.
- Automatische Eintrittsprüfung, KI-Namensprüfung und Watchlist-Hinweise beim
  Spielerbeitritt sind wieder aktiv.
- Der unmittelbare Teamkill-Schutz nach dem Verbinden wird wieder ausgelöst.
- Die vollständige Handler-Liste wird nun in automatisierten Tests geprüft;
  außerdem muss die gemeinsame Runtime die Registrierung nachweislich vor dem
  Live-Ereignisloop ausführen.

### Update-Sicherheit

- Datenbank, Konfigurationen und bestehende Belohnungsstände werden nicht
  verändert. Es ist keine Datenbankmigration erforderlich.
- Die RAM- und Prozessvorteile aus v0.9.11 bleiben vollständig erhalten.
- Seeder-VIP arbeitet weiterhin getrennt von den neuen VIP-Belohnungen. Ein
  vorhandener Probelauf- oder Aktivmodus bleibt beim Update unverändert.
- Wie gewohnt sollten PostgreSQL, Redis und Konfiguration vor dem Update
  gesichert werden.

## English

v0.9.12 is an important hotfix for the lightweight shared RCON runtime
introduced in v0.9.11. The shared runtime started the live event loop without
the central handler registration. Periodic services continued to run, while
some features triggered directly by chat, player connections, kills, or round
changes did not react.

### Restored event-driven features

- VIP rewards receive kill, chat, connection, team-switch, and round events
  again. The status command and voluntary balance signup work again.
- The autobalancer once again handles `!balance`, kills, teamkills, team
  switches, and round start/end events.
- Join-time automatic checks, AI player-name analysis, and watchlist join
  notifications are active again.
- Immediate teamkill protection after a player connects is triggered again.
- Automated tests now verify the complete handler set and prove that the
  shared runtime registers it before starting the live event loop.

### Upgrade safety

- The database, configuration, and existing reward state remain unchanged.
  No database migration is required.
- The memory and process savings from v0.9.11 remain fully intact.
- Seeder VIP remains separate from the new VIP rewards. Existing preview or
  active modes are preserved during the update.
- Continue to back up PostgreSQL, Redis, and configuration before updating.
