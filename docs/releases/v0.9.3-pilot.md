# v0.9.3 pilot acceptance

Historical record of the 24 October pilot. The stable v0.9.3 release was
subsequently published and deployed to RCON3/4 on 9 November; current evidence
and remaining observational limits are in the
[stable rollout receipt](v0.9.3-rcon34-rollout.md). Statements below about stable
promotion and `latest` describe the pilot's status at that earlier date.

## Scope

User decision on 24 October 2026: include every committed application change since
v0.9.2, not only the already proven hotfixes, and test the combined candidate on
RCON3/4. Baseline `4058daf6`; original candidate `c4933df4` (32 commits).

Candidate branch: `codex/release-v0.9.3-rc1-20261024`. Published immutable prerelease:
`v0.9.3-rc.1`. No stable release or master merge before acceptance. Stable `latest`
must remain at v0.9.2 (see the corrected tag incident below).
The branch includes the full ancestry; no feature was dropped by cherry-picking.

Only RCON4 then RCON3 are application rollout targets. Keep RCON1/2 stopped and
all other installations unchanged. The central Discord service already carries
the relevant hotfixes: verify compatibility/source hashes before deciding whether
a shared-service restart is needed. Do not conflate the separate WordPress plugin
with this application release or repeat previous account/profile/TLS operations.

## Pilot observation

Check fresh live/map data, round boundaries, persisted player statistics, Discord
delivery/actions, report-admin decisions and reporter receipts, error rates,
service health and resource use. Installation alone is not behavioral proof.

Use synthetic isolated tests for deliberate sanctions. No unsolicited test
messages, reports, kicks or team moves. Normal configured live moderation remains
possible. Self-report testing is an existing explicit exception on RCON3/4; do not
silently enable it elsewhere or change it as part of this rollout.

The new member and teamkill execution paths need particular observation. Cheating
continues to require human action. HLL-specific seeding and map behavior cannot
be fully accepted solely on the HLLV pilot; keep HLL automated regression checks
and obtain separate approval for any later HLL pilot.
