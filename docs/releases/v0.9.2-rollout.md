## Outstanding external issues

### Hosted HLL certificate

`hll-2464-88.crcon.fln.gg` serves the certificate for `crcon.fln.gg` and
`*.crcon.fln.gg`, issued by Let's Encrypt YR2. It expired on **2026-09-26 at
15:16:36 UTC**, before this rollout. The renewal configuration uses the manual
authenticator with no renewal hook. The enabled Certbot timer cannot automate
that DNS challenge by itself.

Application services, internal HTTP and authenticated read-only APIs pass. Public
HTTPS and password-reset acceptance remain blocked; certificate validation was
not disabled. The user was asked to choose an automatically renewable certificate
for this specific hostname or renewal of the shared wildcard with DNS access.
No shared proxy, certificate or DNS configuration was changed without that choice.

### Existing game-server connection errors

Ente1's event loop had 18 `UnicodeDecodeError` occurrences in the hour before its
restart, with two afterwards in the checked window. HLL1 had a connection
reset/broken-pipe error before and after its restart and subsequently supplied
fresh live data. Ente2 had no event-loop errors in the checked post-rollout window.
These are not evidence of a new migration or database integrity failure.

During verification, SQL diagnostic lines beginning with `[` were initially
misclassified as timestamped log entries; the scanner was corrected to require
an actual timestamp. The corrected scan found no new integrity errors.

The hosted deployment check also required a timestamp-parser compatibility fix
for the host's Python version. It was rerun successfully without database
downgrade or application rollback. No release image was modified.
