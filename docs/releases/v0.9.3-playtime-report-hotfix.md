# RCON3/4 pilot hotfix — 2026-10-24

## Scope

Backend-only patch on top of the immutable v0.9.3-rc.1 image. No new public
release, moved tag, schema change, moderation-policy change or model call.
Only RCON3/4 are authorized; other installations remain unchanged.

## Round playtime

Clamp each adjusted connection interval to the requested statistics window and
to a non-negative duration before summing. A late arrival inside the estimated
100-second cooldown or a departure before the inferred warmup must not create
negative playtime, nor subtract time from an earlier valid connection.
Existing warmup/cooldown conventions and combat counts remain unchanged.
Consequently a player joining 51 seconds before the end has **0 adjusted round
seconds**, not -49; this is not a claim that their actual connection lasted zero
seconds. Live statistics (no cooldown discount) still count those 51 seconds.

Historical rows are not rewritten by this code change. A separate, backed-up
data correction requires approval and must not claim to reconstruct actual
historical connection duration by merely replacing a negative value with zero.

  Adjacent team snapshots show REALPB7 staying squad leader in Golf. A transient

The hotfix distinguishes malformed interpretation/data, unresolved original
target, unresolved current target, changed identity/seat, and disabled rules.
Failed guards retain bounded original/current target and reporter state plus
duplicate-ID/seat counts, without saving a second complete roster. Human-readable
German/English reasons replace the misleading combined ambiguity message.
No guard is relaxed and no old report is retried or player kicked by this audit.
