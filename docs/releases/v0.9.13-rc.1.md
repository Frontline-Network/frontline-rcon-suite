# Frontline RCON Suite v0.9.13-rc.1

## Deutsch

Dieser Release Candidate bündelt die Änderungen seit v0.9.12 für Hell Let Loose und Hell Let Loose: Vietnam.

- **Voice-Meldungen.** Am PC beginnt `!admin` einen Dialog. In Discord können auch Konsolenspieler einen Vorfall melden und den Zielspieler auswählen. Bei einer Voice-Meldung erhält der Spieler einen privaten Hinweis. Der Melder erfährt, ob der Spielserver den Versand bestätigt hat. Nach der Rückfrage kann ein Teilnehmer des betroffenen Sprachkanals mit Ja oder Nein antworten. Vor einem aktivierten automatischen Kick prüft Frontline Runde, Sitzung und Rolle erneut. Admins können währenddessen andere Vorfälle übernehmen. Fertige KI-Auswertungen erhalten Vorrang vor noch wartenden Anfragen.
- **VIP und Kampagnen.** Einladungen beim zweiten Besuch verweisen auf „Spielidentitäten“. Pro Probezeitraum ist eine Ablauferinnerung vorgesehen. Reconnects und Serverwechsel werden bei der Zustellung berücksichtigt. Reguläre Belohnungen und Seed-VIP erhalten die bestehende Restlaufzeit. Ungültige Importdaten oder Ablaufdaten überschreiben bestehende Rechte nicht. Ein VIP-Entzug bleibt beim Vietnam-Abgleich auch bei unterschiedlicher Groß- und Kleinschreibung der EOS-ID wirksam.
- **Moderation und Bannlisten.** Frontline prüft beim No-Leader-Automod vor der Strafe erneut, ob das Squad noch ohne Leader ist. Der Bannlistenabgleich berücksichtigt unabhängige Spielbanns und neuere Admin-Entscheidungen. Barricade-Custom-Scans sind an die zugeordnete Integration gebunden. Der automatische CRCON-Abgleich historischer Barricade-Einträge mit ungeklärter Eigentümerschaft bleibt offen (#404).
- **Spielerakten, Karten und Matchende.** Die Spielerübersicht lädt Suchfelder früher und begrenzt bei der ID-Suche die Auswertung der Sitzungshistorie. VIP-Nachrichten erscheinen unter „Nachrichten“. Die taktischen Karten für HLL wurden aktualisiert, Vietnam-Karten zeigen die HQs im Maßstab der Spielerpositionen. Spieler ohne Team oder Squad bleiben in der Liste. Leere Positionsdaten am Kartenursprung unterbrechen die Spur. Die konfigurierbaren Matchende-Nachrichten können Spieler- und Squad-Ranglisten getrennt anzeigen. Die französische Übersetzung wurde erweitert.
- **Update von v0.9.12.** Backend und Frontend gemeinsam aktualisieren. Das Update führt Datenbankmigrationen aus. PostgreSQL, Redis und Konfiguration vorher sichern. Auf RCON3 wurden HLL und Vietnam jeweils im Split- und Unified-Modus isoliert getestet, einschließlich wiederholtem Update und Rückkehr zum alten Anwendungscode. Ein Code-Rückfall lässt das migrierte Datenbankschema bestehen.

## English

This release candidate includes the changes since v0.9.12 for Hell Let Loose and Hell Let Loose: Vietnam.

- **Voice reports.** On PC, `!admin` starts a conversation. Console players can also report an incident and select a player in Discord. For a voice report, the target receives a private prompt. The reporter is told whether the game server confirmed delivery. A participant in the affected voice channel can answer the follow-up with Yes or No. Before an enabled automatic kick, Frontline checks the round, session and role again. Admins can take over other incidents while a response is pending. Completed AI assessments take priority over requests still waiting for a response.
- **VIP and campaigns.** Second-visit invitations link to Game Identities. Each trial has one expiry reminder. Delivery accounts for reconnects and server changes. Regular rewards and Seed VIP preserve remaining VIP time. Invalid import data or expiry dates do not overwrite existing entitlements. A VIP revocation survives Vietnam reconciliation when the letter case of the EOS ID differs.
- **Moderation and ban lists.** The No-Leader rule checks that the squad still lacks a leader before applying a punishment. Ban-list reconciliation respects independent game bans and newer admin decisions. Barricade Custom scans are scoped to the registered integration. Automatic CRCON reconciliation of historical Barricade entries with unresolved ownership remains open (#404).
- **Player records, maps and match end.** The player overview shows search controls earlier and narrows session-history queries when searching by ID. VIP messages appear under Messages. HLL tactical maps have been updated, and Vietnam HQ overlays use the same scale as player positions. Players without a team or squad remain in the list. An empty position at the map origin breaks the trail. Configurable end-of-match messages can show player and squad rankings separately. French translations have been expanded.
- **Upgrading from v0.9.12.** Update the backend and frontend together. This update runs database migrations. Back up PostgreSQL, Redis and configuration first. Isolated RCON3 tests covered HLL and Vietnam in both split and unified API modes, including a repeated upgrade and a return to the previous application code. A code rollback retains the migrated database schema.
