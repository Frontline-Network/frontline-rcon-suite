# Frontline RCON Suite v0.8.6

## Deutsch

Dieses Update schließt Lücken in der englischen Bedienoberfläche. Die Sprache
lässt sich wie gewohnt über das Sprachmenü auswählen.

- **Autobalancer:** Live- und Teamansicht, Vorschlagsprüfung, Sicherheitsmeldungen,
  Erklärungen, Historie, Pilot-Auswertung und Diagramme sind auf Englisch verfügbar.
- **Live-Karte:** Bekannte Prüfhinweise, Archiv- und Fehlermeldungen werden in der
  gewählten Sprache angezeigt. Namen, Fallnotizen und andere Benutzertexte bleiben
  unverändert.
- **Einstellungen und Discord-Anbindung:** Fehlende Beschriftungen der Spiel-,
  Wetter- und Kamerasteuerung sowie bekannte Ergebnisse von Führungsabstimmungen
  wurden ergänzt.
- **Sprachwechsel:** Tabellen, gespeicherte Ansichten, Datumsfelder, Monatsnamen
  und Zahlenformate reagieren auf die Sprachauswahl. Die Dokumentensprache ist
  auch nach einem direkten Einstieg auf Englisch korrekt.
- **Fehlermeldungen und Aktionen:** Wiederholte technische Fehler, Bestätigungen
  und Rückmeldungen verwenden die ausgewählte Sprache.
- **Schutz vor neuen Lücken:** Automatische Prüfungen vergleichen deutsche und
  englische Kataloge, Platzhalter und Übersetzungsaufrufe. Neue Browser-Tests
  prüfen Englisch auf Desktop und Mobilgeräten sowie den Wechsel ohne Neuladen.

Das Update ändert keine Moderationsregeln, Kick-Berechtigungen oder gespeicherten
Servereinstellungen. Es benötigt keine zusätzliche Datenbankmigration gegenüber
v0.8.5. Individuelle Nachrichten, Spielerchat und unbekannte technische Details
werden nicht automatisch umgeschrieben. Veröffentlichung und Server-Rollout sind
getrennte Schritte; dieses Release aktiviert keine Funktionen auf Servern.

## English

This update closes gaps in the English interface. Select English in the language
menu as usual.

- Localized the live/team balance assistant, proposal review, safety notices,
  explanations, history, pilot evaluation and charts.
- Translated known live-map evidence hints, archive messages and errors.
- Completed game, weather and camera controls, leadership-vote outcomes and
  shared action/error feedback.
- Fixed language changes for tables, date pickers, month names, number formatting
  and the document language on initial load.
- Added translation-catalog, interpolation and reference checks, plus desktop
  and mobile browser regression tests.

Moderation rules, kick permissions and saved server configuration are unchanged.
No additional database migration is required compared with v0.8.5. Player names,
chat, configured messages, case notes and unknown technical details are preserved.
Publishing this release does not deploy it or enable any server feature.
